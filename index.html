03 / Open-source project

UniERP

A self-hostable, multi-tenant ERP platform in active development.

View project ↗

UniERP began as a monorepo and now uses a layered collection of repositories. The public code separates the Next.js web client, NestJS API, shared contracts, and Prisma data layer.

  • TypeScript services and API modules in NestJS.
  • Next.js and React client with a separate design system.
  • Prisma and PostgreSQL models, migrations, and data access.
  • Redis and BullMQ for queues and background work.
  • Architecture documents and AI agent development rules guide implementation and review.

The platform is a personal project in progress; repository structure and documented plans are not claims of production readiness.
